Informativa sulla privacy

Ultimo aggiornamento: 28 settembre 2026.

Dati a cui accede l'applicazione

Fedora Customizer configura rclone con l'autorizzazione concessa dall'utente per accedere ai contenuti del suo Google Drive. L'accesso consente di visualizzare, creare, modificare, spostare e rimuovere file per conto dell'utente tramite il mount locale.

Uso e conservazione

I dati di Google Drive vengono trasferiti direttamente tra Google e la macchina dell'utente tramite rclone. Fedora Customizer non gestisce un server remoto, non raccoglie copie dei file e non riceve dati personali dell'utente. La configurazione OAuth e i token sono conservati localmente nella macchina dell'utente e possono essere inclusi soltanto nel backup cifrato creato dall'utente.

Condivisione

Fedora Customizer non vende, condivide o trasferisce a terzi i dati ottenuti tramite le API di Google. Il trattamento tecnico necessario all'accesso ai file è eseguito da Google Drive e rclone.

Revoca dell'accesso

L'utente può revocare in qualsiasi momento l'accesso dalle impostazioni di sicurezza del proprio account Google oppure eliminando il remote e il file di configurazione rclone dalla propria macchina.

Contatti

Per informazioni è possibile utilizzare l'indirizzo di assistenza mostrato nella schermata di consenso OAuth di Google.
